## How It's Made:

**Tech used:** GraphQl, Apollo, MongoDB, Express, React, Node, Javascript, CSS

Developed using the MERN stack, this project showcases my skills in crafting scalable web applications. I utilized GraphQL for efficient data queries and management, Apollo for seamless client-server interaction, and CSS for styling, ensuring a smooth and intuitive user experience. The app follows a modular design pattern, making it easy to maintain and extend.

## Optimizations
- Implemented well-designed schemas and an MVC architecture to enhance performance and scalability.
- Organized code by separating queries and mutations, which facilitates maintenance and future feature integration.
- Planned upcoming features such as Google Authentication and enhanced sorting functionalities for improved usability.




## Lessons Learned:

- Gained in-depth knowledge of GraphQL and Apollo, significantly improving my ability to handle complex data interactions.
- Understood the importance of a well-structured architecture, which aids in maintaining clarity and scalability.
- The experience has strengthened my approach to building scalable and maintainable web applications, which will benefit future projects.
